# 共創世界窗：離線互動示範

這是供評審直接在瀏覽器操作的靜態展示版，不需要 Node.js、API 金鑰或後端伺服器。

## 操作

1. 點「開始試玩」，畫一個角色後點「畫好了」。
2. 確認預設名字或替角色取名。
3. 在副駕區選擇三種預設規則之一。
4. 輸入過河辦法，選擇直接出發或替代辦法。
5. 可再試其他辦法、進隧道，或重新開始。

鍵盤快捷鍵：S 開始、T 加速到隧道、A 再試一個辦法、R 重置。

## 展示範圍

- 圖畫由使用者命名，不提供 AI 圖像辨識。
- 辦法使用預設關鍵字判斷與預寫選項，不是 AI 即時判斷。
- 每個分頁各自遊玩，不提供跨裝置同步；重新整理會重置。
- 不要求麥克風權限，不上傳畫作或文字，不包含 API 金鑰。
- 有可用的本機中文語音時可播放提示，否則以畫面文字為主。
- 初次開啟需要網路下載網頁資源；此處「離線」指遊戲不呼叫 AI 或應用後端。
- 窗外景色為程式模擬，不是真實車窗或 GPS 連動。
